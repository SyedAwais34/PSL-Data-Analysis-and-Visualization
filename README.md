# 📊 PSL Data Analysis & Visualization

A complete data analysis and visualization project based on the Pakistan Super League (PSL). This project explores PSL datasets using Python libraries to analyze team performance, player statistics, match trends, and generate meaningful insights through visualizations.

## 🚀 Features
- 📈 Data Cleaning & Preprocessing  
- 📊 Statistical Analysis of PSL Matches  
- 🏏 Team Performance Comparison  
- ⭐ Top Player Analysis  
- 🔥 Match Winning Trends  
- 📉 Data Visualization using Graphs & Charts  
- 🧠 Insights from PSL Historical Data  

## 🛠️ Technologies Used
- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn
